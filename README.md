# nox-demo-string-utils

A tiny string-utils package that exists solely as a live demo target for
[Nox](https://github.com/sehynn/nox) — an unattended overnight coding-agent
skill. The issues on this repo are real Nox tickets; the draft PRs it opens
are real, unedited output.

## Functions

- `reverse(str)` — reverses a string
